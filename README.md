## What I Do

I build **production-grade backend systems** and **full-stack applications** that handle real traffic, real payments, and real-time interactions. My work spans multi-vendor marketplaces, on-demand service platforms, UK tradesperson lead engines, and web apps — all deployed on cloud infrastructure with proper CI/CD pipelines.

**Core focus areas:**

- **Backend Architecture** — Scalable REST APIs, microservices patterns, background job queues (BullMQ), caching layers (Redis), and full-text search (Elasticsearch)
- **Payment Engineering** — Stripe Connect split payouts & escrow, Google Play / App Store in-app subscription verification, PayPal, SSLCommerz, Hubtel
- **Real-time Systems** — WebSocket clusters with Socket.io, live video streaming with Agora, real-time bidding engines
- **Cloud & DevOps** — AWS deployments, Docker containerization, Terraform IaC, automated CI/CD
- **AI Integration** — OpenAI & Gemini API integration, Agentic AI workflows for intelligent automation
